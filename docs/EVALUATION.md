# 算法与闭环评测方案

以下是待执行方案，不是已取得的真实精度。当前自动化测试证明逻辑约束，不证明人体动作模型泛化。

## 数据与划分

初步邀请 8–12 位知情同意成年人，覆盖不同身高、体型、衣着、光照与摄像头距离。每动作录制正常、未完成、暂停、出画、遮挡等情况，避免要求用户故意做危险动作。取得视频存储与使用选择；标注者审阅计数和问题，原始资料不入 Git。

按用户划分调参、验证、最终测试，禁止同人邻近片段随机分散到训练测试。小样本结果只支持原型结论。标准计数与纠错定义由有训练经验者审阅，标注分歧记录后裁定。

## 指标

| 能力 | 指标／实验 | 初期目标与限制 |
|---|---|---|
| 计数 | 每组绝对误差、MAE、漏计、误计 | 清晰机位争取 MAE ≤1；不是现有结果 |
| 纠错 | 每问题 precision、recall、误报/分钟 | 优先避免持续误报，定义依据先冻结 |
| 质量门控 | 遮挡、出画、错误视角拒绝评价 | 错误视角当前未自动识别，必须单列 |
| 个体适配 | 固定阈值 vs 归一化＋校准 | 新用户改善才算收益 |
| 性能 | 有效分析 FPS、P50/P95 帧端到端延迟、CPU/RAM | 固定设备、分辨率、浏览器、模型版本 |
| 计划 | 约束满足率、修改合理性、用户可理解性 | 同一回放输入比较，固定规则边界 |
| 多 Agent | 固定计划 vs 单 Agent vs 多 Agent | 同模型、同工具、近似计算预算；不要靠提示长度作弊 |
| 热量 | 单位、公式、分段、总／净口径 | 无测热真值不报预测准确率；手表不是无误差金标准 |
| 隐私 | 运行期网络请求、保存选择、删除 | 断网重启，不仅当前页面断网 |

建议记录 30–60 秒每组、每动作多个组，按实际人数报告样本量；具体数量取决于用户时间和有效样本。不为达到指标删掉失败机位而不说明。

## 有价值的消融

1. 去掉可见性门控，观察跨遮挡计数与误报变化。
2. 去掉个体校准，比较跨用户误差（功能实现后）。
3. 去掉主观疲劳反馈，比较计划与用户感受的一致性。
4. 多 Agent 对比单 Agent，检查真实约束收益是否抵消额外延迟。

## 当前自动化检查

后端：高疲劳降低目标、证据不足保持计划、不适禁止确认、旧版本冲突、非法时长、无同意不落盘、能耗体重比例、本地模型地址限制。前端：角度退化、完整动作计数、不可见不计数、丢失追踪不跨缺口计数。

这些测试可进入 CI。真实用户验证、机位自动判别、设备性能、断网重启和实际 LLM 质量需要单独记录在 VALIDATION，不能由单元测试代替。
