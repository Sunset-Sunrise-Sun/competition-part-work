# 架构决策记录

## ADR-001：先交付训练闭环（2026-10-09）

背景：4–5 人，约三周提交，多模态原设想范围过大。

决策：两个动作＋质量门控＋反馈＋计划确认是 P0；表情、照片份量、语音、自训模型按完成程度延期。

后果：能积累可验证核心证据；覆盖范围有限，展示必须说明。

## ADR-002：实时规则与慢速 Agent 分离

决策：计数、暂停、质量门控在浏览器规则层；Agent 组间与组末处理。所有计划调整经过规则和用户确认。

后果：LLM 故障不阻塞训练；模型只能解释／提出受约束提案，不能逐帧自由指挥。

## ADR-003：确定性协作作为首个可运行基线

决策：v0.1 使用轻量 Python 编排器，四角色结构化 trace；LangGraph 后续接入，API 不变。

后果：降低基础框架成本，但不能宣称已完成自主多智能体或 LangGraph。用对比实验判断引入模型协作的收益。

## ADR-004：同机端侧与远程增强分开

决策：笔记本完成核心；4090 与 A100 开发训练；同机 LLM 可选。权重和资源提前准备。

后果：纯离线演示有清晰数据边界；远程模式后续需独立说明。

## ADR-005：Markdown 源文档＋独立 HTML 展示

决策：团队日常维护 Markdown，在 GitHub Review；导出无外部依赖 HTML 用于交流和打印。

后果：便于共同版本管理；PDF 手动打印后不作为主源，每次生成从 Markdown 同步。
